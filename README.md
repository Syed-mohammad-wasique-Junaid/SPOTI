# 🎵 SPOTI

**SPOTI** is a modern Spotify-inspired music streaming web application built using **HTML, CSS, and JavaScript**. It provides a clean UI, responsive design, playlist browsing, music controls, and an immersive listening experience.

## ✨ Features

* 🎧 Spotify-inspired modern interface
* 📱 Fully responsive for desktop & mobile
* ▶️ Play, pause & skip music controls
* 🎼 Playlist and album-style layout
* 🔊 Interactive music player with progress bar
* 🌙 Dark theme with smooth animations
* ⚡ Lightweight and fast performance

## 🛠️ Tech Stack

* **HTML5** – Structure
* **CSS3** – Styling & Responsive Design
* **JavaScript (ES6)** – Player Logic & Interactivity

## 🚀 Getting Started

1. Clone the repository

```bash
git clone https://github.com/Syed-mohammad-wasique-Junaid/SPOTI.git
```

2. Open the project folder

```bash
cd SPOTI
```

3. Launch `index.html` in your browser.
